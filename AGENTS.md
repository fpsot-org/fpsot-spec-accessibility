# Instructions for agents

This repository holds the FPSOT accessibility specification: the WCAG 2.2 level AA baseline of FPSOT products, the accessibility values, testing, accessibility statements and procurement.

- The normative text is in `spec/en/` and `spec/fr/`. Every rule has an ID such as `ACC-001`.
- Follow `skill/SKILL.md` when you build or review a screen, a theme, a document, a chart, a test or a statement. The spec text wins on any difference.
- Contrast, focus, target size, motion and text alternative values live only here. Other specifications point to them and never restate them.
- Every page exists in English and in French, with the same file name and the same IDs.
- Terms and abbreviations come from the term base of `fpsot-spec-writing`. Add a missing term there first.
- Do not copy text from outside standards. Summarize them in your own words and cite the exact version.
- Commits follow Conventional Commits and are signed. Pull requests are squash-merged.
