## [0.1.1] - 2026-11-07

### Changed

- Accessibility values: the page states once, above the values table, that sizes are in CSS pixels; the table cells use the short form. No value changes.
- Index (English): notes the W3C candidate authorized French translation of WCAG 2.2, as the French index does, and lists it under informative references.
- The archived copy of EN 301 549 uses the same address as its link (`etsi_en`).
- French wording: « fonctionner » replaces « marcher », « billet » replaces « ticket », and « composants d’interface » replaces « widgets ».

## [0.1.0] - 2026-11-05

### Added

- Baseline ACC-001 to ACC-006: WCAG 2.2 level AA, its scope over web pages, documents and mobile apps, four level AAA criteria, sign language, versions and exceptions.
- Accessibility values ACC-010 to ACC-019: contrast, color, focus, target size, flashes, motion, text alternatives, text size and layout.
- Web pages and apps ACC-020 to ACC-028: keyboard, native elements and WAI-ARIA, structure, forms, sign-in, status messages and time limits, help, mobile apps and gestures.
- Documents and media ACC-030 to ACC-035: documents, tagged PDF, document structure, web forms first, captions and media players.
- Testing ACC-040 to ACC-047: automated checks, manual and assistive technology checks, the test record and failures.
- Statements and procurement ACC-050 to ACC-059: accessibility statements, conformance claims and reports, calls for tenders and outside components.
- Comparison with the international baseline, Canada and Québec.
- An explanation guide and a how-to guide in each language.
