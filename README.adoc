= FPSOT accessibility specification

This specification sets how FPSOT products serve people with disabilities.
Its baseline is WCAG 2.2 level AA, with four level AAA criteria that Québec requires.
It covers web pages, documents and mobile apps, testing, accessibility statements and procurement with EN 301 549.
It also owns the values for contrast, focus, target size, motion and text alternatives that the style and diagrams specifications use.

== Implement this spec

Read the normative text in `spec/en/` or `spec/fr/`.
Each requirement has an ID, such as `ACC-001`.
Check each screen, document and app against every requirement, and keep a test record under ACC-045.
`skill/SKILL.md` gives a one-page summary.

== Adopt this spec

Read the guides in `docs/modules/en/pages/` or `docs/modules/fr/pages/`.
They explain why one profile serves Canada and Québec, and show how to test a release.
To require the spec in a call for tenders, cite its version and requirements ACC-055 to ACC-058.
The comparison data in `jurisdictions/` shows how the federal and Québec rules differ from the FPSOT default.

== Layout

[cols="1,3"]
|===
| Folder | Content

| `spec/`
| Normative text, in English and French. `book.adoc` joins the pages into one book.

| `docs/`
| Guides, in the Antora folder layout.

| `skill/`
| The agent skill: a short summary that cites requirement IDs.

| `rules/`
| Machine-checkable rules.

| `diagrams/`
| PlantUML sources and their rendered SVG files.

| `jurisdictions/`
| Comparison data per jurisdiction. `baseline.yaml` lists the compared requirements.
|===
